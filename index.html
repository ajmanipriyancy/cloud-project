UCS531 Cloud System Architecture

1. Presentation Tier

HTML5, Tailwind CSS, Vanilla JS, Chart.js hosted on Netlify Global CDN over HTTPS

2. Serverless Compute

Supabase PostgreSQL RPC (Serverless Database Function) executing demand prediction

3. Cloud Data Tier

Managed PostgreSQL (BaaS) storing menu, live preferences & wastage records

Weighted Statistical Demand Model:

Predicted_Demand = ROUND( 0.70 × Current_Student_Preferences + 0.30 × Historical_Daily_Average )

Why 70/30 weighting? Live student pre-bookings capture same-day appetite shifts (70% weight), while historical averages buffer for walk-in students who don't pre-book (30% weight). Weights can be tuned via regression to minimize Mean Absolute Error (MAE).
